<div class="lang-zh">

> **用自然语言描述一个研究目标，把生物医学图像变成可核对、可复现的洞察。**
>
> [GitHub 仓库](https://github.com/zhentai-sn/open-glaux) · 0.2.0 · Pre-alpha

Glaux 是一个懂生物医学影像的智能体，以及它工作所需的一整套环境。智能体负责理解和规划，环境负责把事做对：带物理标定的分割与测量，覆盖超声、CT 和病理切片。

它最初是一个"环境优先"的科学内核，外面包着一个 IDE 和一层意图解析；后来转向让智能体住进环境：界面改为对话优先，智能体通过工具调用内核干活，它提出的标注要由人确认才生效。

目前仍是 Pre-alpha，定位是科研洞察，而非临床决策。

<div class="lang-en">

> **Describe a research goal in plain language, and turn biomedical images into insight you can check and reproduce.**
>
> [GitHub repository](https://github.com/zhentai-sn/open-glaux) · 0.2.0 · Pre-alpha

Glaux is an agent that understands biomedical images, together with the environment it needs to do the work. The agent understands and plans; the environment makes sure things are done right, with calibrated segmentation and measurement across ultrasound, CT and pathology slides.

It started as an "environment-first" science core wrapped in an IDE and an intent-parsing layer, then pivoted to letting the agent move in: the UI became chat-first, the agent now works through tools that call the core, and the annotations it proposes take effect only when a person confirms them.

It is still pre-alpha, aimed at research insight, not clinical decisions.
