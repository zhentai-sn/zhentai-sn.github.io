> **把图像与视频交给一个在本机工作的智能体环境，让分析过程和证据都能复核。**
>
> [项目主页与下载](https://zhentai-sn.github.io/open-glaux/) · [GitHub 仓库](https://github.com/zhentai-sn/open-glaux) · [v0.3.0 发布页](https://github.com/zhentai-sn/open-glaux/releases/tag/v0.3.0)

Glaux 是本机运行的图像与视频分析智能体环境。你接入兼容的模型，Glaux 提供文件工作区、看图与视频问答、标注、测量和分割工具。围绕图像提问，或让智能体查看一段视频，回答可以结合画面、时间点与对齐的音频证据。

智能体可以放大和检查图像，提出标注后由人复核、修正或撤回；运行轨迹保留模型调用与工具过程，Atlas 可保存可复用案例。从看图到标注和测量，分析过程在同一个工作区内完成，具体工具取决于所接入的数据和模型。

项目从“环境优先”的内核与 IDE，逐步转向让智能体通过工具调用内核。0.3.0 将这套体验打包为完整的本机版本，提供 Windows、Linux 和 macOS 安装器，以及一键更新与本地运行命令。用户数据保存在本机，程序包不包含专用模型权重。

<div class="lang-en">

> **Analyze images and video with a local agent environment, and keep the work and evidence open to review.**
>
> [Project home and downloads](https://zhentai-sn.github.io/open-glaux/) · [GitHub repository](https://github.com/zhentai-sn/open-glaux) · [v0.3.0 release](https://github.com/zhentai-sn/open-glaux/releases/tag/v0.3.0)

Glaux is a locally running agent environment for image and video analysis. Connect a compatible model, and Glaux provides a file workspace plus tools for image and video questions, annotation, measurement, and segmentation. Ask about an image or have the agent inspect a video; answers can draw on frames, timestamps, and aligned audio evidence.

The agent can zoom in and inspect images. Its proposed annotations can be reviewed, revised, or withdrawn by a person. Run trajectories preserve model and tool activity, while Atlas stores reusable cases. Image inspection, annotation, and measurement happen in the same workspace; the available tools depend on the data and models connected.

Glaux began with an "environment-first" core wrapped in an IDE, then shifted to an agent that works through tools calling that core. Version 0.3.0 packages the experience for local use, with installers for Windows, Linux, and macOS, plus one-command updates and local runtime commands. User data stays on the machine. Dedicated model weights are not included.
